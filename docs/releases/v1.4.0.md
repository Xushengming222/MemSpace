# MemSpace 1.4.0

- 游戏保护默认开启：前台游戏、全屏应用或演示期间暂停自动强力释放。保护结束后重新等待至少 45 秒高占用；手动强力仍可执行，设置可关闭。
- 托盘后台每 10 秒采样，隐藏页面停止刷新；恢复后立即更新并切回 2 秒刷新。趋势按实际时间保留最近两分钟。
- 托盘直接显示内存占用百分比，85% 起橙色、95% 起红色。右键提供强力释放、后台释放和游戏保护状态；图标只在数字或尺寸变化时重绘并释放旧资源。

## 下载

下载附件 `MemSpace.exe`，退出旧版（包括托盘中的程序）后双击新版即可运行。高 DPI 支持内置于 EXE，单独下载也能清晰显示。`MemSpace-1.4.0.zip` 另含兼容配置、使用说明和 MIT 许可证。

需要 Windows 10 / 11 与 .NET Framework 4.8。游戏保护不执行任何强力清理；常见游戏识别无法覆盖全部软件。后台释放仍沿用前台、近期活动及排除名单保护。

## 验证

带配置和单 EXE 两种方式均通过 106 项自测及界面回归；在 150% 桌面缩放下均为 144 DPI / PerMonitorV2。自测覆盖游戏识别与全屏边界、暂停后重新计时、低频刷新、实际时间趋势、托盘数值边界和旧设置兼容。界面回归覆盖四个页面、三档字号、五种窗口大小、真实无边框全屏与普通最大化测试窗口、隐藏页面不刷新、托盘恢复、数字图标复用与 GUI 资源回收。助手测试使用探针，不执行系统强力清理。
