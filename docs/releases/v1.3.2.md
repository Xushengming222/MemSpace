# MemSpace 1.3.2

修复单独下载 EXE 时界面模糊的问题。显示器 DPI 声明现已内置于程序，Windows 不再把整个窗口作为图片放大，文字、按钮和图表按实际屏幕缩放绘制。

## 下载

下载附件 `MemSpace.exe`，退出旧版后双击新版即可运行。单独下载也支持高 DPI，无需额外配置文件。`MemSpace-1.3.2.zip` 另含兼容配置、使用说明和 MIT 许可证。

需要 Windows 10 / 11 与 .NET Framework 4.8。强力释放完成后继续只在状态栏显示结果。

## 验证

带配置与单 EXE 两种方式均通过 87 项自测及界面回归。在 150% 桌面缩放下，两者均报告 144 DPI 与 PerMonitorV2，绘图 DPI 与窗口一致。检查四个页面、三档字号、五种窗口大小、应用选择和托盘恢复；未在不同 DPI 的双显示器间实测切换。助手通信使用探针，不执行系统强力释放。
