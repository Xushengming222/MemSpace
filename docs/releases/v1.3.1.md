# MemSpace 1.3.1

取消手动强力释放完成后的结果弹窗，不再需要额外关闭结果页面。完成结果显示在主窗口状态栏，详细步骤继续写入本地日志。

## 下载

下载附件 `MemSpace.exe`，退出旧版后双击新版即可运行。`MemSpace-1.3.1.zip` 另含高 DPI 配置、使用说明和 MIT 许可证。

需要 Windows 10 / 11 与 .NET Framework 4.8。管理员授权、释放操作和自动触发规则沿用 1.3.0。
