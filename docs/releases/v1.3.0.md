# MemSpace 1.3.0 · 内存管家

首次公开发布，源码采用 MIT 许可证。

## 下载与运行

直接下载附件 `MemSpace.exe`，双击即可启动。需要 Windows 10 / 11 与 .NET Framework 4.8；无需额外安装 Python 或 Node。

`MemSpace-1.3.0.zip` 包含程序、高 DPI 配置、使用说明和许可证。使用此包时解压后运行文件夹内的 `MemSpace.exe`，保留 `.exe.config` 在同目录以启用多显示器 DPI 配置。

`Source code` 压缩包是源码，直接使用请下载 EXE 或便携包。程序暂未进行代码签名。

## 本版功能

- 内存概览、应用/进程排行、开机排查与本地诊断报告。
- 后台释放，以及覆盖系统的强力释放。
- 自动强力释放复用本次运行的管理员授权，达到阈值持续 45 秒触发，自动操作间隔至少 15 分钟。
- 自动识别常见游戏、录屏与工作软件；排除名单支持搜索和勾选应用。
- 三档字号、窄窗口布局、最小化到系统托盘。

自动释放与登录启动默认关闭。强力释放作用于整个系统，不能遵守逐应用排除规则，可能短暂卡顿；排除名单仅作用于后台释放。授权在退出软件后失效，重新运行需再次授权。实际回收量取决于系统负载，占用可能回升。

发布前通过 85 项本地检查与四页、三档字号、多尺寸界面验证。系统级操作的自动测试采用不执行内存操作的探针，未进行实际强力释放量的对照测试。
