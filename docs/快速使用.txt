MemSpace · 内存管家 1.3.0

1. 双击 MemSpace.exe，无需安装，通常无需管理员权限。
2. “占用排行”默认按应用汇总，可切换到单个进程。双击查看进程、路径与保护原因。
3. 需要临时缓解压力时，点击“释放后台内存”。它只释放闲置程序的工作集，不关闭程序；内存可能回升。
4. 要降低开机常驻占用，打开“开机排查”→“Windows 启动设置”，核实并关闭你不需要的第三方启动项，再重启比较。
5. 自动释放和登录启动默认关闭，可在“设置”开启后保存。
6. 点击标题栏的最小化按钮或“收起到托盘”，窗口会进入系统托盘，不保留最小化的任务栏窗口。双击托盘图标或点击“打开内存管家”恢复；关闭窗口或从托盘点击“退出”会退出软件。
7. 在“设置”选择 100%、125%、150% 字号，点击“保存设置”后生效并记住选择。
8. 启动项会显示已知的启用/禁用状态。未标记或未知的项，请到 Windows 启动设置核实。
9. 需要更大范围的临时回收时，点击“强力释放”，允许 Windows 的管理员权限提示。它依次回收系统工作集、刷新修改页并清空待机列表，完成后显示实测变化和各步结果。
10. 缩小窗口后，顶部“菜单”可切换页面；按钮会换行，卡片会改为纵向排列。向下滚动查看全部内容，表格的宽列可在表格内部横向滚动。
11. 需要自动强力释放时，勾选相应复选框并保存，或点击“授权管理员”。允许 Windows 的权限提示后，本次运行复用授权；超过阈值持续 45 秒触发，共用 15 分钟冷却，自动结果保存到日志。重新打开软件需再次授权。
12. 排除名单默认开启自动识别，会按已知程序名与安装目录保护常见游戏、录屏和工作软件。点击“选择应用”搜索并勾选补充，无需输入进程名。旧名单保留。
13. 页面详细介绍移到“使用帮助”，日常页面只保留操作和状态。

后台释放会保护前台、近两分钟用过的应用及其进程家族、仍有 CPU 或读写活动的程序。
强力释放作用于整个系统，不能遵守排除名单，会影响正在使用的应用，可能短暂卡顿或增加磁盘读写。自动强力仅在已勾选且本次运行已授权时触发，同时开启两种自动模式时优先使用已授权的强力模式。
取消勾选自动强力或退出软件会结束授权会话；退出不会撤回已开始的系统操作。自动触发不会再次弹出 UAC。自动识别不能覆盖所有软件，前台与读写保护始终生效。
应用工作集合计可能重复包含共享页，不能当成去重后的物理内存占用。

无法保证释放指定容量。活跃程序、驱动和硬件保留内存不会因此消失。
请在“选择应用”中勾选自动识别尚未覆盖的游戏、录屏、音频或其他对延迟敏感的软件。
强力释放的执行范围与分析到的启动器实现相同，但无法保证每次释放 3 GB 或更多；程序重新加载数据后占用可能回升。

删除软件前，如开启过登录启动，请先关闭这一项并保存。
保留 MemSpace.exe.config 在 EXE 同目录。
需要 Windows 10 / 11 和 .NET Framework 4.8。

灵感来源：龙腾猫跃的 PCL 内存优化入口；本工具独立实现，没有复制 PCL 的百宝箱代码。
